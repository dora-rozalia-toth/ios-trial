# AI Boards — iPad Panel-Behavior Prototype — Spec

Date: 2026-10-15
Source: Figma "AI Boards iOS Book viewer" → "Govern AI panel stater - latest version"
(frames: `Side nav open / content / structure`, `GovernAI open`, `GovernAi & Side nav open`)

## Goal

A clickable prototype that lets stakeholders **play with the side panels** of an iPad
(landscape) book/document viewer. The right **GovernAI** panel opens like the info/inspector
panel in Apple Preview on iPad: it slides in from the right and **pushes/resizes** the content
rather than overlaying it. Built two ways so stakeholders can compare:

- **A — Web** (`web/`): self-contained vanilla HTML/CSS/JS, no build step, shareable link.
- **B — Native SwiftUI** (`swiftui/`): Xcode project, iPad landscape, real materials + SF Symbols.

Both implement the **same state machine and visual spec**. "Panels are the star": transitions
are fully live; document/outline content is realistic but static (non-navigating).

## Canvas & layout

- Device canvas: **1366 × 1024** (iPad Pro 12.9", landscape).
- Horizontal three-pane split (widths from Figma):
  - **Content sidebar** — 320 pt, collapsible (left).
  - **Document** — fills remaining width; narrows as panels open.
  - **GovernAI inspector** — 400 pt (right).
- Floating **glass toolbar layer** over the document top:
  - Leading pill: `[sidebar-toggle] [back]` + book title.
  - Trailing pills: `[annotate] [add]` group, and a separate **✦ AI (GovernAI)** button.

## State machine

Two independent booleans: `sidebarOpen`, `governAIOpen`.

| Trigger | Effect |
| --- | --- |
| Tap ✦ AI (open) | `governAIOpen = true`; **`sidebarOpen = false` (auto-collapse)**; AI button → highlighted purple; trailing group **splits** (annotate/add stay, sparkle lifts into panel header); GovernAI panel springs in from right, document resizes narrower. |
| Tap sidebar-toggle while AI open | `sidebarOpen = true`; both panels coexist ("both open" frame). Auto-collapse happens **only at the moment AI opens**, so the sidebar can be brought back. |
| Tap ✦ AI (close) | `governAIOpen = false`; panel slides out right; document re-expands; sparkle returns to trailing group, de-highlights. |
| Tap sidebar-toggle, AI closed | Toggle `sidebarOpen`; plain collapse/expand push. |

### Figma annotations (verbatim) this satisfies
1. "When AI panel is opened, the sidenav collapses."
2. "Button group splits when AI button is tapped. The AI panel opens on the right and pushes the rest of the buttons on its left."
3. "When active, the AI button has a highlighted color."

## Panel contents

### Content sidebar
- Header "Content"; segmented **Structure / Thumbnails**.
- Glass icon toolbar row: list, search, share, annotate, bookmark.
- Outline tree: Agenda; 1. Review of Key Financial Metrics (expanded) with document leaf rows,
  1.1 Revenue, 1.2 Expenses (expanded, nested to 1.2.1.1), 1.3 Profit Margins, etc. One row shown
  selected (highlighted).

### Document (center)
- Running header "GlobalTech Industries | Board of Directors — Governance & Risk Committee".
- Sections: "4. Audit Committee Report" (High Priority Findings bullet list, Medium & Low
  Priority), "5. Resolutions Pending Board Approval" (navy table: Resolution / Proposed By /
  Status), "6. Committee Sign-Off", confidential footer. Enough content to scroll.

### GovernAI inspector
- Header: ✦ sparkle + "GovernAI", kebab (⋯), expand (⤢), active ✦ button.
- Tabs: **Smart Assist / Insights** (Insights active).
- Breadcrumb "‹ Smart Summary".
- Meta line: "Last updated on Apr 30, 2026, 11:24:40 AM · ✦ Generated by AI" (AI disclosure).
- **Executive Summary** card: Financial reports / Strategic updates topics, "Show more".
- **Detailed Summary** card: Financial reports → document + subtopic entries.

## Visual tokens (from Figma)

- Font: **Inter** everywhere (UI + document); SF Pro / SF Symbols for glyphs where native.
- Ink `#232429`; secondary `#575a67` / `#676767`; document headings navy `#455d82`;
  table header navy (dark); accent blue `#0040d5`; status red `#87222f`; AI accent purple.
- Surfaces: white content, light-gray app background; panels divided by hairline separators.
- Glass pills: functional layer only — backdrop blur + translucent fill + hairline highlight.

## Motion

- Panel in/out + document resize: spring, ~0.38 s. Toolbar split + AI highlight animate together.
- **Reduced motion** (web `prefers-reduced-motion`, SwiftUI Reduce Motion): crossfade / instant,
  no slide.

## Accessibility floor

- Icon-only controls get accessible labels (title/aria-label / `.accessibilityLabel`).
- Hit targets ≥ 44×44 pt. Text ≥ 11 pt. Contrast meets 4.5:1 (body) / 3:1 (large) with the tokens above.

## Out of scope

Outline navigation, real AI/content generation, Thumbnails content, kebab/expand actions
(visual only), portrait/compact layouts, multiple documents.
